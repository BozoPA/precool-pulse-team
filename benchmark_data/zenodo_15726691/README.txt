## Description
This repository contains the raw data for the cooling tunnel system described in the article:  
“Wind tunnel system to apply precooling airflow and cooling conditions for fruit chilling injury assessment” – submitted to *MethodsX*.

## Contents
Zip file containing the following files:
	- CI Data.xlsx
	- Cooling Tunnel Calibration Data.xlsx
	- Industry FAC Trial Temp Data.xlsx
	- Industry Static Trial Temp Data.xlsx
	- Laboratory Trial FAC Temp Data.xlsx
	- Laboratory Trial Static Temp Data.xlsx
- README.txt : Overview and instructions
- LICENSE.txt : Licensing terms

## Usage
These files are intended for research and educational use. Refer to the MethodsX article for detailed methodology and integration guidance.
